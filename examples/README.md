# Anypoint Connect examples

Every identifier in this directory is synthetic. Replace placeholders only in local, ignored files and
never commit a Client Secret.

| Example | Purpose |
| --- | --- |
| [`cli/readiness.sh`](cli/readiness.sh) | Verify a profile and environment from bash/zsh |
| [`cli/readiness.ps1`](cli/readiness.ps1) | Verify a profile and environment from PowerShell |
| [`mcp/`](mcp) | Pinned Claude, VS Code, and Codex MCP configurations |
| [`library/`](library) | Build-free JavaScript application listing using an authenticated profile |

Complete the [Getting started](https://avinava.github.io/anypoint-connect/getting-started/) flow first.
The examples do not create a Connected App, authorize a user, or bypass confirmation gates.
